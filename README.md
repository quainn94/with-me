# WITH ME Life v0.4.0

생활 식비 · 식재료 · 레시피 · 체중 기록 앱.

## v0.4.0
- 레시피 수정 기능
- 레시피 먹기 기록 시 구성 식재료 자동 소진
- 미래 날짜는 `예정`으로 저장하고 완료 시 소진 반영
- 레시피 사용 기록 삭제 시 자동 생성된 소진 기록도 함께 삭제
- 완제품 레시피 수정 시 원가/칼로리 재계산

## 업데이트
1. 기존 `with-me` 폴더에 파일을 덮어씁니다.
2. 기존 `.env.local`은 유지합니다.
3. Supabase SQL Editor에서 `supabase/setup_v0.4.sql`을 새 Query로 1회 실행합니다.
4. `npm run build`로 확인합니다.
