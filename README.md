# WITH ME Life v0.2.0

장보는 순간 바로 기록하고, 내 음식만 원가·예상 식비·칼로리 계산에 쓰도록 흐름을 다듬은 버전입니다.

## v0.2 핵심 변경
- 구매가 시작점: 구매 탭에서 처음 보는 재료 이름을 입력하면 식재료가 자동 생성됩니다.
- 가족 장보기와 내 식단 분리: 모든 구매 이력은 남기되 `내 식단` 재료만 단가/월 예상비용/레시피 계산에 사용합니다.
- 사용 기록 수정/삭제: 날짜별 최근 기록에서 잘못 입력한 사용량을 바로 고칠 수 있습니다.
- 직접 사용 vs 소진 기록: `오늘 또띠아 2장`과 `깻잎 300g을 5일 만에 소진`을 구분합니다.
- 채소 폐기 포함: 소진 기록에 `시들어서 버린 양도 포함` 체크가 있습니다.
- 최근 7일 평균: 식재료 카드에 오늘 사용량, 최근 7일 평균 사용량, 내 월 예상비용을 나눠 표시합니다.
- 레시피는 내 식단 재료만 선택하며 원가와 kcal를 자동 계산합니다.

## Supabase 업데이트
v0.1.0을 이미 사용 중이면 기존 `setup_v0.1.sql`을 다시 실행하지 않아도 됩니다.
Supabase SQL Editor에서 `supabase/setup_v0.2.sql`만 1회 실행하세요.

이 SQL은 기존 기록을 지우지 않으며 기존 `households`, `app_data`도 건드리지 않습니다.
